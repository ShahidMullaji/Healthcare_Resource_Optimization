# Healthcare_Resource_Optimization Dashboard


An interactive Power BI dashboard built to help hospital network stakeholders monitor patient admissions, hospital resource utilization, and billing performance across facilities — replacing scattered manual reports with a single, consolidated view.

Overview

Hospital administrators often lack one place to see patient volumes, capacity pressure, and financial performance together. This project consolidates admissions, hospital, and billing data into a 4-page Power BI report so stakeholders can spot trends and act on them without pulling numbers from multiple sources.

Dashboard pages

1. Overview Network-wide KPIs at a glance — total patients, total hospitals, total billing, average billing, emergency admissions, average length of stay — plus monthly admission trends, admission-type split, and top hospitals by patient count.

2. Patient & Admission Analysis Demographic and admission-pattern insights — average patient age, admission rates by type, admissions by year/month, age-group and gender breakdowns, and medical condition distribution.

3. Hospital Resource Analysis Per-hospital utilization — average patients per hospital, average LOS by hospital, billing by hospital, emergency admission share, and a sortable hospital-level detail table.

4. Financial & Clinical Analysis Billing and payer-mix analysis — billing by hospital and medical condition, average billing by admission type, billing by insurance provider, and patient counts by medication.

Key features
Cross-filtering slicers for hospital, date, admission type, medical condition, and age group on every page
KPI cards for at-a-glance metrics
Trend, distribution, and ranking visuals (line charts, donut charts, treemaps, bar charts)
Detailed drill-down table with totals for hospital-level reporting
Tech stack
Power BI Desktop — data modeling, DAX measures, report design
DAX — calculated KPIs (average LOC, emergency/urgent/elective rates, billing per patient, etc.)
